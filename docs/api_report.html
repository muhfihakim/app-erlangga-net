2. Network Client & Authentication Architecture

  • Environment Configuration: Runtime configuration loaded from assets/flutter_assets/.env containing BASE_URL=https://stage.erlangga.net/api.
  • Authentication Token: Bearer token via HTTP header Authorization: Bearer <tokenUser>.
  • Token Persistence: Stored locally as tokenUser via flutter_secure_storage (backed by Android Keystore / Tink AES-GCM EncryptedSharedPreferences).
  • Session Invalidation (401 Handling): Intercepts HTTP 401 Unauthorized, logs [UNAUTH] Sesi berakhir..., calls removeTokenUser, and redirects to /login.
